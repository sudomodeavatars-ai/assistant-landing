# Ассистент

Статичный лендинг продукта «Ассистент» для финансовой ясности.

## Локальный просмотр

```bash
node server.mjs
```

После запуска сайт будет доступен на `http://127.0.0.1:4173`.

## Публикация на GitHub Pages

Проект уже содержит workflow `.github/workflows/pages.yml`. После push в ветку `main` GitHub Actions соберёт и опубликует сайт через GitHub Pages.

Если Pages не включится автоматически, в репозитории нужно открыть `Settings → Pages` и выбрать `Source: GitHub Actions`.
